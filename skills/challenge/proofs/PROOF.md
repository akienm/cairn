## The gate

The skill class's derivation gate retired with the tool that ran it (ticket
`d547b4859f9a`, outline 19.6): `cairn help` is the one help surface (2.4.2). This
skill's gate is its own proofs, sealed by the tester, like every code-seam.

## v0 behavioral check (hand-run)

- `/challenge` fires the five questions on UNSETTLED thinking, before a `/sorted` claim.
- The "real collision?" question asks the *why of each side* — it does not flag a
  distinction as a contradiction (see the memory `ask-the-why-to-distinguish`).
- A design that fails the pass is routed back or out, not rubber-stamped.
- A pass that finds nothing says so honestly (a measured null result), it does not
  manufacture an objection.
